# 🌈 WonderKids World

> Learn • Listen • Play • Explore

WonderKids World is a modern Kids Learning & Entertainment Platform built with React.js, Node.js, Express.js, MongoDB, and JWT Authentication.

The platform provides a safe, engaging, and educational environment where children can read stories, listen to audiobooks, watch cartoons, play games, solve puzzles, learn through videos, and enjoy personalized AI-powered experiences.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/yourusername/WonderKidsWorld.git

cd WonderKidsWorld
```

### Install Dependencies

Frontend:

```bash
cd client
npm install
```

Backend:

```bash
cd server
npm install
```

---

## ⚙️ Environment Variables

Create a `.env` file inside the server folder:

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

JWT_REFRESH_SECRET=your_refresh_secret

OPENAI_API_KEY=your_openai_api_key

YOUTUBE_API_KEY=your_youtube_api_key

GOOGLE_BOOKS_API_KEY=your_google_books_api_key
```

---

## ▶️ Run Application

Backend:

```bash
npm run dev
```

Frontend:

```bash
cd client
npm run dev
```
